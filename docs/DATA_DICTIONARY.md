# 数据字典与维护说明

## 人口数据

`public/data/population.json`（2010）与 `public/data/population2020.json`（2020）：年份、来源、全国记录和31省区市记录。默认使用2020，可统一切换年份。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| year | number | 所选统计年份，2010或2020 |
| sourceUrl | string | 官方原表地址 |
| regions[].code | string | 六位省级行政区代码 |
| regions[].name | string | 源表地区简称 |
| regions[].total | number | 同表地区人口合计，单位人 |
| regions[].populations | object | 56个民族名称映射到人口，单位人 |
| populations[民族] | number/null | 非负整数；null为源表空白 |
| sourceId | string | census2010或census2020-A0104 |
| unidentified / naturalized | number/null | 2020原表未识别民族与入籍外国人人口，用于完整合计核查 |

不要按地区名称连接其他数据。`code`与GeoJSON `properties.adcode`转换成字符串后关联。香港、澳门、台湾及南海几何可能有地图对象，但本版没有接入对应同口径省级人口。

高山族页另提供2026年9月底台湾官方原住民户籍统计参考，采用独立数据对象，不写入2010或2020大陆人口矩阵。台湾参考标注虚线边界、类别与时点，详见`TAIWAN_STATISTICS.md`。

## 民族资料

`src/data/catalogue.ts`：56个民族，按普查表顺序整理。

`national2020`是2020年大陆人口原表数；省级占比始终使用同年同地区人口和分母。`majorRegions`是年鉴列出的定性主要地区，`description`和文化标签为编辑概述。

`culture-profiles.json`按56民族保存六类栏目：`id`、栏目名称、选题、正文、来源类型、原文URL、机构、保存快照、SHA-256、获取日期、证据及编辑核查日期。旧来源未记录获取时间时保留`null`，不补造。319个栏目有证据，17个明确待核查。选择条目在`scripts/culture-selections.json`维护。

`cultural-places.json`保存56个行政地区代表点：民族、行政区代码、所属省代码、参考经纬度、原文证据、地区来源和坐标来源。不是村落或文化建筑的精确坐标，不含县级人口。`directory.ts`构建地名、文化主题检索索引，名称/拼音匹配优先于全文关键词。

2020民族原表数据不含港澳台，页面使用“大陆普查人口”明确范围。高山族3,479人为大陆普查数，不代表台湾人口。

## 经济数据

`src/data/economy.ts`：2023年初步核算数，来自年鉴2024表3-9。

| 字段 | 单位 | 说明 |
| --- | --- | --- |
| gdp | 亿元 | 地区生产总值，当年价格 |
| perCapita | 元 | 人均地区生产总值 |
| sectors | 亿元 | 第一、第二、第三产业增加值 |
| growth | % | 可比价格GDP指数减100，即实际增长率 |
| autonomous | boolean | 是否为五个民族自治区之一 |

产业增加值与GDP可能因原表四舍五入存在0.1亿元左右差异。不得将人均GDP改名为“人均收入”。

## 计算

- 当地民族人口占比：当地该民族人口 / 当地同表总人口 × 100%。
- 地区分布份额：当地该民族人口 / 已收录省区市该民族人口合计 × 100%。
- 前五地区集中度：人口数量最多的五个有效地区合计 / 已收录地区该民族人口合计 × 100%。
- 缺失值不进入排名，地图使用灰色；真实零值进入排名且使用最浅级。
- 数量分级：[0,1000)、[1000,10000)、[10000,100000)、[100000,1000000)、[1000000,+∞)。
- 占比分级：[0,0.1)、[0.1,1)、[1,5)、[5,20)、[20,+∞)，单位%。

## 原表与采集记录

- `data/raw/census2010.html`：完整HTML原表，GB18030解码。
- `data/raw/A0104.jpg`：2020省级民族人口原表，小计列已发布；整理和校验见`POPULATION_2020.md`。
- `data/raw/A0201.jpg`：2020全国民族人口。
- `data/raw/C03-09.jpg`：2023省级经济。
- `data/raw/C25-18.jpg`：主要分布地区与2020民族人口。
- `data/raw/content_5597952.htm`：改革开放与减贫历程白皮书快照。
- `data/manifest.json`：自动采集URL、字节数、SHA-256和UTC获取时间。

网页使用静态快照，发布构建不重新爬取数据，避免来源网站不可达时影响部署。采集前应遵守来源服务的访问条件；图片和边界来源保留归属说明。

## 民族发展内容

`src/data/reform.ts`：1978、1982、1994、2000、2011、2013、2020、2021八个节点，来源为2021年《人类减贫的中国实践》白皮书。内容为概述；连接到2023经济模块时明确说明经济数据只是单年截面。

`src/data/development.ts`：56个民族的发展线索、文化特色与176条文化保护记录，覆盖2006—2024年。国家级名录核对2006、2008、2011、2014、2021批次，另有7个UNESCO记录；`src/data/heritage-additions.json`保存113条补充记录，区分新增与扩展项目，2021图片附件人工转录。每项成果保存年份、范围、机构、原文URL与证据。地区卡片按主要分布地区匹配2023经济与所选2010/2020人口，不定义为民族GDP；高山族大陆案例与台湾户籍资料单列。原文快照和校验和保存在`data/raw/development/`，详见`docs/ETHNIC_DEVELOPMENT.md`。

`recent-cases.json`保存11条2025—2026年地方案例，均支持原文核查；`year`表示事件或明确标注的报道年份，`period`保留时段/“报道”提示，`reportedAt`表示原页面日期。日期不代表文化起源。`ethnic-timeline.ts`把历史事件、近期案例与文化保护成果合并排序；`stories.ts`优先选取有依据的近期地方事件，再回退到原有历史故事。

## 人口版本维护

2020矩阵核查与发布已完成。修改时须重新核对民族纵向合计、地区横向合计、特殊项目、独立全国表及图表统一年份；流程与核查产物见`POPULATION_2020.md`。不得用省级、全国比例或面积推算缺失记录。
