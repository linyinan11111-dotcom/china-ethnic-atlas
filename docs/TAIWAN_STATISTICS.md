# 高山族与台湾人口统计口径

“高山族3,479人”来自国家统计局2020年第七次全国人口普查表2-1，是大陆普查民族数据，不含台湾人口。2010年大陆省级表高山族合计4,009人。此前页面使用“全国人口”标签容易误读，现标为“大陆普查人口”。两项原表数字保持其年份和范围。

台湾数据来自[内政部门户政司《民國115年9月戶口統計資料分析》](https://www.moi.gov.tw/News_Content.aspx?n=9&sms=9009&s=342353)，2026年10月8日发布。报告第九项采用“原住民”户籍登记分类；第二项给出同月户籍总人口。民国115年对应2026年。

| 指标 | 2026年9月底 |
| --- | ---: |
| 原住民登记人口 | 641,332人 |
| 户籍总人口 | 23,213,251人 |
| 占当地总人口 | 2.76% |
| 花莲县原住民人口 | 95,096人 |
| 桃园市原住民人口 | 92,202人 |
| 台东县原住民人口 | 79,758人 |

县市前三名直接采用该报告的排序与数字，并不宣称已采集完整县市表。条形长度及县市份额的分母为641,332人，**不是县市自身总人口**。当地总人口占比由641,332÷23,213,251×100%得到，四舍五入为2.76%，与原文一致。

两种资料的时间、调查方式和民族/户籍分类不同，不相加为“全国高山族总人口”，不加入2010年的大陆省级排名或集中度。地图中台湾采用虚线边界及星号作为单独参考，悬停、点击显示类别与时点；大陆仍按2010普查色阶展示。其他民族未采集台湾对应分类数据，保持缺失状态。

来源原文快照：`data/raw/taiwan/household-2026-09.html`。结构化数据：`src/data/taiwan-indigenous.json`，含SHA-256、来源、采集与发布日期。`npm run taiwan:fetch`重复采集该已选定报告；更换统计月份需同时更换官方原文、检查页面口径与校验值。

排名、表格和地图的百分比统一使用`formatPercent`，不改变排序所用原始数值。小于0.1%的数据增加显示小数位；极小非零值显示`<0.0001%`，真实零显示`0%`，缺失显示`暂无数据`。图表提示显示百分号或人数单位，并预留右侧标签空间；占比接近100%时坐标上限为100%。
