# 民族插画头像

当前专题封面、民族目录和搜索结果均使用用户提供的服饰插画裁切头像。

- 原图：[昵图网预览](https://pic.nximg.cn/file/20240409/35284279_092240047105_2.jpg)，956×1024，8列×7行。
- 完整原图：`public/avatars/ethnic-sheet.jpg`。
- 独立头像：`public/avatars/ethnic-1.png` 至 `ethnic-56.png`，编号沿用人口普查民族顺序；不是原图格子顺序。
- 对应表：`src/data/ethnic-avatars.json`，含民族、文件、原图行列、裁切坐标、尺寸、原图SHA256与核对状态。
- 裁切脚本：`scripts/crop-ethnic-avatars.py`，使用Pillow；不放大、不去背景、不覆盖或修复水印。

## 对应关系与限制

朝鲜族为第7行第4列；蒙古族为第3行第4列。此前样例误标的第4行第3列实际为普米族，第3行第1列实际为满族。

原图第1行第5列名称被图案遮挡，第1行第8列文字不清。目前暂配布依族、景颇族，两条记录均为 `mappingStatus: pending`，封面与数据说明明确标记待核查。取得高清原图后应优先核对，不能把暂配关系视为已核查的服饰资料。

每格约100×132像素，适合小尺寸头像。插画是艺术示意，不能概括整个民族的服饰，也不能据此判断真人身份。原图未提供开放许可；裁切与署名不会改变原图许可。

## 替换方法

替换某民族头像时，按对应表找到 `file`，用新PNG覆盖同名文件即可。若更换格式或路径，同步修改对应表的 `file`、来源与核对状态。整个头像系统支持Vite的GitHub Pages子目录部署。

原人物照片与其来源清单仍保存在 `public/photos/` 与 `docs/PHOTO_SOURCES.md`，当前页面不再引用。
