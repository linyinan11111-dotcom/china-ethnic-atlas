## 液态玻璃改版 · 2026-10-28

- 根据本地 `D:/lyn/program/geoask/web` 的实现接入 [Lens 液态玻璃](https://ruiqichenbiec.github.io/design-systems/)，原始渲染器与 MIT 许可证保存在 `src/vendor/lens/`。
- 封面使用真实 WebGL2 折射；页头、目录、章节导航、地图工具和内容面板使用透明层、反光边缘与背景模糊。地图、图表、头像和文字保持各自原生渲染。
- 调整中英文字体、正文及说明字号、按钮间距、表格对比度和手机布局；已有 100×132 像素头像保留原图，缩小展示尺寸以减少过度放大。
- 没有 WebGL2 时自动使用 CSS 玻璃效果；系统设置减少透明度时切换实色面板，减少动画时停用交互过渡。封面离屏停止绘制，组件卸载释放显卡资源。
- 五个章节使用可拖拽的透镜导航：按住横向拖动，松手吸附并跳转到对应章节；支持点击、手机触摸以及方向键、Home/End。民族目录与搜索中的每个选项加入玻璃表面，透镜覆盖层随悬停及键盘选择弹性移动；移除颜色名称标签。
- 修复拖拽松手后选中层先回旧章节再前进的问题：平滑跳转途中保持目标章节，滚动结束或访客主动滚动后恢复章节检测。
- 新增高像素密度、360–1920px 布局、WebGL 不可用、减少透明度和封面重新挂载的浏览器检查。设计来源、效果边界及维护入口见 [液态玻璃设计说明](GLASS_DESIGN.md)。
- 本轮验证：21 项单元测试、40 项浏览器测试通过，数据校验、格式检查、严格类型检查与生产构建通过。
